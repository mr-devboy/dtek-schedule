# ⚡️ DTEK Schedule

Автоматичне отримання графіку планових відключень електроенергії від ДТЕК зі сповіщеннями в Telegram.

## 💖 Підтримка

Якщо проєкт корисний для вас не забудьте поставити ⭐️ та [підтримати донатом](https://send.monobank.ua/jar/3QTpZrNn2T).

## 📋 Опис

Проєкт автоматично отримує графік планових відключень електроенергії на сайті ДТЕК для вказаної групи та відправляє сповіщення в Telegram з детальним розкладом на поточний день. Перевірка розкладу запускається щогодини через GitHub Actions.

## ✨ Можливості

- 🤖 Автоматичне отримання графіку відключень електроенергії щогодини.
- 📱 Надсилання сповіщень в Telegram з детальним розкладом на день.
- ♻️ Оновлення існуючого повідомлення замість створення нових (одне повідомлення на день).
- 📊 Відображення часових проміжків з електроенергією та без неї.
- 🌙 Тихі сповіщення в нічний час (00:00-08:00).
- 🔄 Автоматичний запуск через GitHub Actions.

## 🚀 Швидкий старт

### 1. Форк репозиторію

Натисніть кнопку "Fork" у правому верхньому куті сторінки репозиторію.

### 2. Створення Telegram бота

1. Відкрийте [@BotFather](https://t.me/BotFather) в Telegram.
2. Відправте команду `/newbot`.
3. Вкажіть ім'я та username для бота.
4. Збережіть отриманий токен (формат: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`).

### 3. Отримання Chat ID

1. Відправте будь-яке повідомлення вашому боту.
2. Відкрийте в браузері `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`.
3. Знайдіть значення у форматі `"chat":{"id":123456789}` — це ваш Chat ID.

### 4. Визначення вашої групи відключень

1. Перейдіть на сайт ДТЕК вашого регіону, наприклад [КРЕМ](https://www.dtek-krem.com.ua/ua/shutdowns).
2. Введіть вашу адресу (місто, вулиця, будинок).
3. Знайдіть та збережіть в результатах номер вашої групи (наприклад `1.2`).

### 5. Налаштування Secrets

Перейдіть в **Settings** → **Secrets and variables** → **Actions** вашого форкнутого репозиторію та додайте наступні secrets:

| Secret               | Опис                                    | Приклад                                                                                          |
| -------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `TELEGRAM_BOT_TOKEN` | Токен бота від BotFather                | `123456789:ABCdefGHI...`                                                                         |
| `TELEGRAM_CHAT_ID`   | ID чату в Telegram                      | `123456789` або `-123456789` (для каналу)                                                        |
| `REGION`             | Регіон ДТЕК                             | `k` — Київ, `kr` — Київська обл., `dn` — Дніпровська обл.,`o` — Одеська обл.,`d` — Донецька обл. |
| `GROUP`              | Номер групи відключень без префіксу GPV | `1.2`                                                                                            |
| `PAT`                | Personal Access Token для GitHub        | [Інструкція](#створення-pat)                                                                     |

#### Створення PAT

1. Перейдіть в **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens**.
2. Натисніть **Generate new token**.
3. Підтвердіть доступ одним із запропонованих методів, наприклад `Use GitHub Mobile`.
4. Вкажіть назву токена, наприклад `dtek-schedule`.
5. Встановіть термін дії (або `No expiration` на свій розсуд).
6. Оберіть **Repository access** → `Only select repositories` та оберіть клонований репозиторій.
7. Натисніть **+ Add permissions** → відмітьте `Read access to metadata` та `Read and Write access to code`.
8. Натисніть **Generate token** та скопіюйте токен.

### 6. Запуск Actions

1. Перейдіть на вкладку **Actions**.
2. Знайдіть та відкрийте workflow з назвою **"Run power outages schedule generator"**.
3. Праворуч вгорі натисніть **Run workflow** → і ще раз на **Run workflow** всередині випадного меню.

## 🛠 Локальний запуск

### Вимоги

- Node.js (версія вказана в `.nvmrc`)
- npm або yarn

### Встановлення

```bash
# Клонування репозиторію
git clone https://github.com/YOUR_USERNAME/dtek-schedule.git
cd dtek-schedule

# Встановлення залежностей
npm install
# або
yarn install

# Встановлення Playwright залежностей
npx playwright install chromium
```

### Налаштування

Створіть файл `.env` в кореневій директорії з наступним вмістом:

```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHAT_ID=-12346789
REGION=kr
GROUP=1.2
```

### Запуск

```bash
# Для разового запуску
npm run start
# або
yarn start

# Для автоматичного перезапуску
npm run watch
# або
yarn watch
```

## 🔍 Як це працює

1. **Отримання даних**: Скрипт використовує Playwright для відкриття сайту ДТЕК та парсингу даних про графік відключень.
2. **Генерація розкладу**: На основі отриманих даних формується детальний розклад з годинними та напівгодинними інтервалами.
3. **Формування повідомлення**: Створюється структуроване повідомлення з переліком часових проміжків відключень.
4. **Відправлення в Telegram**: Повідомлення відправляється боту, з тихим режимом у нічний час (00:00-08:00).
5. **Оновлення повідомлення**: Якщо повідомлення вже було відправлено сьогодні, воно оновлюється замість створення нового.
6. **Збереження стану**: Інформація про останнє повідомлення зберігається в файлі та комітиться в репозиторій як артефакт.

## ⚙️ Налаштування

### Зміна частоти перевірки

Відредагуйте cron вираз у файлі `.github/workflows/schedule.yml`:

```yaml
schedule:
  - cron: "0 * * * *" # щогодини
```

Приклади:

- `*/30 * * * *` - кожні 30 хвилин
- `0 */3 * * *` - кожні 3 години
- `0 6,12,18 * * *` - тричі на день (6:00, 12:00, 18:00)

### Додавання декількох груп

Для моніторингу декількох груп створіть окремі репозиторії або дублюйте workflow з різними secrets.

## 📝 Формат груп

Проєкт підтримує групи у форматі **GPVX.X**, де:

- X.X - номер вашої групи (наприклад, 1.1, 2.3, 5.1)
- В налаштуваннях вказується лише число без префіксу GPV

Приклади валідних груп:

- `1.1` → GPV1.1
- `2.3` → GPV2.3
- `5.1` → GPV5.1

## 🕐 Стани електропостачання

Проєкт розпізнає чотири типи станів:

- **Електроенергія є** - повна година з електроенергією.
- **Електроенергії немає** - повна година без електроенергії.
- **Перша половина без світла** - 00-30 хвилин без світла, 30-60 хвилин зі світлом.
- **Друга половина без світла** - 00-30 хвилин зі світлом, 30-60 хвилин без світла.

## ⚠️ Обмеження

Графік не зможе працювати у разі недоступності сторінки `/shutdowns` або зміни структури даних на ній.
